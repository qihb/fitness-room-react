# 登录页背景图 · 落地计划

**目标**：把登录页从「灰底 + 白卡」升级为「全屏背景 + 毛玻璃居中卡片」，提升观感，登录逻辑保持不变。

**技术栈**：见 AGENTS.md（React 19 / Vite+ / antd 6 / Tailwind v4 / react-router 8）。

**涉及文件**：

- 新增 `docs/plans/2026-10-11-login-background.md`（本文件）
- 修改 `src/pages/login/index.tsx`（背景层 + 毛玻璃卡片）

**关键决策**：

1. 背景来源：原计划用文生图服务生成健身房实景照片本地化到 `public/login-bg.jpg`。**执行时该服务持续只返回「生成中」占位图**（5 次尝试，MD5 恒为 `19a0b82…`，1832×1832），故改用**纯 CSS 深色光影背景兜底**（无外网依赖）；待图片可用时可一步替换。
2. 卡片承载：换成 Tailwind 毛玻璃 `div`（避开与 antd `Card` 背景 token 冲突）。

**执行约定**：本文件仅为计划；由用户指定步骤后再执行，每完成一步勾选 `- [ ]`。
